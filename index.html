📖 How to Play PyQuest
⚡ 1. Code-Gated Combat

Read the monster's trial prompt in the Tome of Wisdom. Type valid Python 3 code and click Cast Spell. Zero free damage—your code must compile and pass validation to strike!

🔥 2. Elemental Weakness (1.5x)

Monsters have affinities: Pyro (strings), Cryo (numbers/modulo), Electro (loops), and Arcane (functions/dicts). Exploit weaknesses for 1.5x damage.

💥 3. Pythonic Mastery (2.0x)

Write idiomatic, clean Python (such as f-strings, list comprehensions, .get(), or built-in functions) to land devastating 2.0x Critical Strikes and bonus gold!

📜 4. Scroll of Truth Safety Net

If you fail 2 attempts, the glowing Ancient Scroll of Truth unlocks with the exact working solution and an Auto-Inscribe button so you never get stuck.
